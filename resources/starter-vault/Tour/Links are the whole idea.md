# Links are the whole idea

Most notes apps file things in folders, and a note can only be in one folder. In Geode, a note can be linked from as many places as it matters, and **every link works in both directions**.

## Look to your right

Open the right sidebar (`Cmd+Shift+R`) and find **Backlinks**. [[Start here]] is listed, because it links to this note. You didn't have to do anything to make that happen.

This is where the value comes from over time. Write a note about a person, a project or an idea, and months later the backlinks show you every place it came up.

## Try it

- [ ] Type `[[` below and pick an existing note from the list that appears.
- [ ] Now link to something that doesn't exist yet, like `[[Things I want to learn]]`, and click it.



> [!tip] You can't do this wrong
> A link to a note that doesn't exist yet is fine. It's a placeholder that becomes a real note when you click it. Some of the best vaults grow this way.

## A small example

The notes in `Reading/` and `Ideas/` show how this adds up. [[How to Take Smart Notes]] links to [[Write in your own words]], and so does [[The Extended Mind]]. Open that idea note and check its backlinks: two books you might never have connected, sitting side by side.
