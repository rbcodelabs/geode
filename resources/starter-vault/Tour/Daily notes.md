# Daily notes

If you don't know where to write something, write it in today's note.

- [ ] Press `Cmd+P`, type **daily**, and choose *Open today's daily note*.

You get one note per day, created on demand. Jot down whatever comes up and link anything worth keeping: `Talked to [[Sam]] about [[Kitchen renovation]]`. The daily note is a quick place to capture, and the links carry each thought to where it belongs.

A week from now, open the note for *Sam* and its backlinks will list every day you mentioned them.
