# Start here

Welcome. This is a **vault**: an ordinary folder of text files on your computer. Geode just gives you a good way to write in it and connect things. Nothing lives in a cloud you don't control, and you can open these files in any other app.

This vault teaches by doing. There are five small moves, and each takes less than a minute. Tick each box when you've done it.

## 1. Write something

- [ ] Replace this sentence with anything on your mind this week. There's no save button: Geode saves as you type.

## 2. Follow a link

- [ ] Click [[Links are the whole idea]].

Words in double square brackets link to other notes. That note will show you the one idea everything else here is built on.

## 3. Make a note by linking to it

- [ ] At the end of this line, wrap a name for something you're working on in double square brackets, the same way step 2's link is written. Click the link you just made.

Geode creates the note the moment you open it. You never have to decide in advance where a thought should go.

## 4. See how things connect

- [ ] Press `Cmd+G` to open the graph.

Every dot is a note, and every line is a link. Your note from step 3 is already in there, connected to this one.

## 5. Find anything

- [ ] Press `Cmd+O` and type a few letters of any note's name.

`Cmd+O` jumps to any note. `Cmd+P` runs any command, so if you're ever wondering "can Geode do…?", ask there.
